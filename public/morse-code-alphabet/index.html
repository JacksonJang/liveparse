Timing and spacing rules

  • Dot: one unit. Dash: three units.
  • Between signals in a letter: one unit of silence.
  • Between letters: three units. Between words: seven units.
  • In text: one space between letters, a spaced slash between words.

Morse code alphabet FAQ

How do I read the Morse code alphabet?

Each letter is a short group of dots and dashes. Inside a letter the signals are separated by a one-unit gap, letters by a three-unit gap, and words by a seven-unit gap. In writing, that becomes one space between letters and a spaced slash between words, so HELLO WORLD is .... . .-.. .-.. --- / .-- --- .-. .-.. -..

What is the difference between a dot and a dash?

A dot is one unit of signal and a dash is three units. The same code works as sound, light, or text as long as those relative lengths and the gaps between them are kept.

Are Morse code numbers always five signals?

Yes. Every digit from 0 to 9 uses exactly five signals in International Morse code: 1 is .---- with one dot, 5 is ..... with five dots, and 0 is ----- with five dashes. That fixed length makes numbers easy to recognise.

Is there Morse code for punctuation?

The ITU standard defines codes for the period, comma, colon, question mark, apostrophe, hyphen, fraction bar, brackets, quotation marks, equals sign, cross, multiplication sign, and commercial at. Other symbols circulating online, such as the exclamation mark, are conventions rather than part of the standard.

Is Morse code the same in every language?

International Morse code covers the basic Latin letters, digits, and the ITU punctuation set. Languages with accented or non-Latin scripts use national extensions, and there is no standard code for emoji or most Unicode symbols.
