About LiveParse

LiveParse is a free, local-first developer data toolkit published at liveparse.com. Every tool parses, formats, converts, or calculates inside your browser tab, so the data you paste never leaves your machine.

Published September 4, 2026Maintained by Jackson Jang

In one sentence: LiveParse (also written Liveparse or Live Parse) is a collection of independent, standards-based browser tools for JSON, YAML, XML, SQL, URLs, timestamps, calendar math, images, Base64, binary, hashes, UUIDs, and JWTs, with no uploads, accounts, advertising, or tracking.

What LiveParse is

LiveParse started in 2026 as a lossless JSON formatter and validator. Most online JSON tools quietly round 64-bit identifiers, drop duplicate object keys, or turn an overflowing exponent into null because they rely on JSON.parse. LiveParse instead parses JSON into its own abstract syntax tree so that every numeric lexeme and every repeated member survives formatting, viewing, comparison, and repair exactly as written.

The same philosophy now applies across the whole site: each LiveParse page is a focused, independent tool with a written explanation of its exact behavior, its limits, and the standard it follows. Where a task cannot be done safely in a browser, such as verifying a JWT signature or validating XML against an external schema, the tool says so instead of pretending.

The name

The name combines live, because results update as you type, and parse, because parsing is the first step of every tool on the site. The canonical spelling is LiveParse with a capital L and P, and the only official website is https://liveparse.com/. Search results for "Liveparse" also surface unrelated open-source repositories and libraries that share the word; none of them are affiliated with this site.

Principles

  • Local-first. Tool input, selected files, and generated output stay in the current browser tab. There is no upload endpoint, formatter API, or database behind the tools.
  • Lossless. Number tokens, duplicate keys, key order, whitespace choices, and byte-exact file contents are preserved or diagnosed, never silently changed.
  • Standards-based. Each tool cites the RFC, W3C, WHATWG, ECMA, or ISO document it implements, and the guides explain where implementations diverge.
  • Bounded. Heavy work runs in disposable Web Workers with explicit size and time limits so that a large or hostile input cannot freeze the page.
  • No dark patterns. No sign-up, no advertising, no affiliate widgets, no client-side analytics, and no optional third-party cookies. The privacy notice lists the small amount of server-side aggregate data that hosting requires.

What the toolkit covers

The full list lives in the footer of every page and in the sitemap. The main families are:

  • JSON: the JSON formatter, validator, and viewer, JSON compare, JSON repair, JSONL parser, JSON to CSV, CSV to JSON.
  • YAML and XML: YAML formatter, validator, viewer, YAML to JSON, JSON to YAML, XML formatter, XML validator, and XML viewer.
  • SQL: a SQL formatter for fifteen dialects with dedicated MySQL, PostgreSQL, BigQuery, and SQL Server pages.
  • Regular expressions: a JavaScript regex tester that highlights matches, inspects capture groups, previews replacements, and stops slow patterns in a local worker.
  • Time and dates: Unix timestamp converter, Discord timestamp generator, age calculator, date calculator, days between dates, business days, time duration, ISO week number, and birthday countdown.
  • Encoding and numbers: Base64 decoder and encoder, URL encoder, decoder, URL parser, query string parser, binary converter, hex converter, binary translator, ASCII table, and Morse code translator.
  • Security and identifiers: hash generator, SHA-256, MD5, file checksum, UUID generator, UUID validator, UUID decoder, JWT decoder, and JWT expiration checker.
  • Images and text: image compressor, image resizer, PNG to JPG, WebP to JPG, WebP to PNG, word counter, and character counter.
  • Guides: the guides hub explains the formats, encodings, and traps behind each tool.

Who builds LiveParse

LiveParse is designed, written, and operated by Jackson Jang, a software engineer based in South Korea. The site is a single-maintainer project rather than a company product, which is why every page states its limits plainly and why new tools are added only when they can be made correct and private in the browser.

Source code and feedback

The website source, including the parsers, workers, SEO checks, and production server, is published at github.com/JacksonJang/liveparse. Bug reports, standards questions, and tool requests are welcome as GitHub issues. Please do not include confidential data in an issue; a minimal reproduction is enough.

How to refer to LiveParse

When linking or citing, use the name LiveParse and the URL https://liveparse.com/. Individual tools can be linked directly, for example https://liveparse.com/sql-formatter/, because every tool page is a stable, independent URL.
