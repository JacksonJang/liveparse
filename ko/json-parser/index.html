JSON을 붙여넣어 포맷팅하고 검증하세요

LiveParse는 브라우저 워커 안에서 무손실 토큰 파서를 실행합니다. 숫자와 중복 객체 멤버가 손실 있는 JavaScript 값으로 변환되지 않으며, 붙여넣은 내용은 아무 곳에도 업로드되지 않습니다.

대화형 JSON 포매터를 불러오는 중…

포맷팅, 검증, 압축, 트리 뷰어를 사용하려면 JavaScript를 활성화하세요.

빠른 시작

온라인에서 JSON을 포맷팅하고 검증하는 방법

  1. 1

    붙여넣거나 열기

    JSON 문서를 붙여넣거나 파일 열기를 사용하세요. 검증이 자동으로 실행되며 첫 구문 오류와 위치를 표시합니다.

  2. 2

    포맷 또는 압축

    공백 2칸 또는 4칸을 선택한 뒤 읽기 좋은 JSON은 포맷, 컴팩트한 출력은 압축을 누르세요.

  3. 3

    탐색 또는 내보내기

    트리 보기로 중첩 값을 탐색하거나 포맷팅된 텍스트를 복사하고 다운로드하세요.

예를 들어 {"id":9007199254740993,"amount":1.2300}을 포맷팅하면 들여쓰기가 추가되지만 9007199254740993과 1.2300은 작성된 그대로 유지됩니다. 중복 키도 보존되고 경고로 표시됩니다. 포맷팅은 JSON 구문을 검사할 뿐 애플리케이션 스키마를 검증하지는 않습니다.

모든 파싱과 포맷팅은 브라우저 워커에서 실행됩니다. 붙여넣은 텍스트와 연 파일은 이 탭에 머뭅니다.

핵심 정리

JSON 포매터란?

JSON 포매터(JSON 뷰티파이어, pretty printer라고도 함)는 압축된 JSON에 일관된 들여쓰기와 줄바꿈을 추가해 사람이 구조를 읽기 쉽게 만듭니다. 포맷팅은 공백만 바꿀 뿐 의도된 객체, 배열, 키, 값은 바꾸지 않습니다.

믿을 수 있는 포매터는 다시 쓰기 전에 입력을 파싱하고 검증해야 합니다. LiveParse는 엄격한 검증, 무손실 포맷팅, 압축, 구문 강조, 검색 가능한 트리 뷰어를 결합했습니다. 네이티브 JavaScript 왕복과 달리 큰 숫자 토큰과 반복 객체 멤버를 작성된 그대로 유지합니다.

실제 페이로드를 위한 설계

왜 LiveParse인가요?

01

설계부터 비공개

입력은 현재 브라우저 탭에 머뭅니다. 파서는 붙여넣은 JSON을 전송, 저장, 기록하지 않습니다.

02

무손실·예측 가능

LiveParse는 모든 숫자 토큰과 반복 객체 멤버를 보존하면서 엄격한 JSON을 검증합니다. JavaScript가 정수를 반올림하거나 오버플로 지수를 null로 바꾸기 전에 경고합니다.

03

빠른 텍스트·트리 보기

컴팩트한 페이로드를 강조된 텍스트로 읽거나 가상화된 트리를 검색하세요. 문서가 커져도 렌더링 크기가 작게 유지됩니다.

04

유용한 오류 맥락

오류 위치를 알 수 있을 때 줄과 칸으로 변환해 첫 구문 문제를 빠르게 찾을 수 있습니다.

JSON to CSV

질문과 답

JSON 포매터·검증기 FAQ

이 JSON 포매터·검증기는 무료인가요?

네. LiveParse는 계정, 사용량 계측, 유료 등급 없이 무료로 사용할 수 있습니다.

입력한 JSON이 업로드되거나 저장되나요?

아니요. 파싱, 포맷팅, 압축, 트리 렌더링은 브라우저 안에서 실행됩니다. 입력은 현재 탭의 페이지 메모리에만 있으며 LiveParse로 전송되지 않습니다.

JSON 파서·검증기·포매터의 차이는 무엇인가요?

파서는 JSON 텍스트를 구조화된 값으로 바꾸고, 검증기는 구문이 유효한지 확인하고, 포매터는 유효한 JSON에 일관된 공백으로 다시 씁니다. LiveParse는 세 기능을 하나의 도구로 결합했습니다. 자세한 비교는 JSON parser vs. formatter vs. validator 가이드를 읽어보세요.

주석과 trailing comma가 거부되는 이유는?

일부 JavaScript 문맥에서는 유효하지만 표준 JSON에서는 그렇지 않습니다. LiveParse는 의도적으로 엄격한 파싱을 사용해 결과가 브라우저, API, 대부분의 프로그래밍 언어가 소비하는 JSON처럼 동작하게 합니다.

객체에 중복 키가 있으면 어떻게 되나요?

LiveParse는 무손실 트리와 포맷팅 출력에 반복된 멤버를 모두 보존하고 중복 위치가 포함된 경고를 표시합니다.

64비트 ID와 아주 큰 숫자도 보존되나요?

네. 9007199254740993, 1e400 같은 숫자 토큰은 텍스트로 저장·복사되며 출력을 위해 변환되지 않습니다. 값이 안전 정수 범위를 벗어나거나 JavaScript 숫자에서 오버플로되거나 재직렬화 시 표기가 바뀌면 LiveParse가 경고합니다.

민감한 API 데이터도 파싱해도 되나요?

로컬 처리가 노출을 줄이지만 가능하면 비밀 값을 제거하고 조직의 데이터 처리 규정을 따르는 것이 좋습니다. 페이지 자체는 인터넷에서 불러오지만 붙여넣은 JSON은 도구가 전송하지 않습니다.
