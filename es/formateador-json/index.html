Por ejemplo, formatear {"id":9007199254740993,"amount":1.2300} añade sangría manteniendo 9007199254740993 y 1.2300 exactamente como están escritos. Las claves duplicadas también se conservan y se marcan. El formateo comprueba la sintaxis JSON; no valida un esquema de aplicación.

Todo el análisis y formateo se ejecuta en un worker del navegador. El texto pegado y los archivos abiertos se quedan en esta pestaña.

Lo esencial

¿Qué es un formateador de JSON?

Un formateador de JSON —también llamado embellecedor o pretty printer— añade sangría y saltos de línea consistentes al JSON compacto para que las personas puedan leer su estructura. El formateo cambia los espacios en blanco, no los objetos, arrays, claves ni valores previstos.

Un formateador fiable debe analizar y validar la entrada antes de reescribirla. LiveParse combina validación estricta, formateo sin pérdida, minificación, resaltado de sintaxis y un visor de árbol con búsqueda. A diferencia de un viaje de ida y vuelta por JavaScript nativo, conserva los tokens numéricos grandes y los miembros repetidos tal como están escritos.

01

Privado por diseño

Tu entrada se queda en la pestaña actual del navegador. El analizador no envía, guarda ni registra el JSON que pegas.

02

Sin pérdida y predecible

LiveParse valida JSON estricto conservando cada token numérico y cada miembro repetido. Avisa antes de que JavaScript pudiera redondear un entero o convertir un exponente desbordado en null.

Preguntas respondidas

Preguntas frecuentes sobre el formateador de JSON

¿Este formateador y validador de JSON es gratis?

Sí. LiveParse es de uso gratuito, sin cuenta, sin medición de uso y sin niveles de pago.

¿LiveParse sube o almacena mi JSON?

No. El análisis, el formateo, la minificación y el renderizado del árbol ocurren localmente en tu navegador. La entrada se mantiene en la memoria de la pestaña actual y no se envía a LiveParse.

¿Diferencia entre analizador, validador y formateador?

El analizador convierte el texto JSON en valores estructurados; el validador comprueba si la sintaxis es legal; el formateador reescribe JSON válido con espacios consistentes. LiveParse combina las tres funciones. Para más detalle, lee JSON parser vs. formatter vs. validator.

¿Por qué se rechazan comentarios y comas finales?

Son válidos en algunos contextos de JavaScript pero no en el JSON estándar. LiveParse usa análisis estricto a propósito para que el resultado se comporte como el JSON que consumen navegadores, API y la mayoría de lenguajes.

¿Qué pasa con las claves duplicadas?

LiveParse conserva cada miembro repetido en su árbol sin pérdida y en la salida formateada, y muestra una advertencia con la ubicación del duplicado.

¿Conserva IDs de 64 bits y números muy grandes?

Sí. Tokens como 9007199254740993 y 1e400 se almacenan y copian como texto, nunca se convierten para la salida. LiveParse avisa cuando un valor supera el rango entero seguro de JavaScript, desborda un número o cambiaría de escritura al reserializarse de forma nativa.

¿Puedo analizar datos sensibles de una API?

El procesamiento local reduce la exposición, pero elimina los secretos cuando sea posible y sigue las reglas de manejo de datos de tu organización. La página se carga desde internet, pero el JSON pegado no es transmitido por la herramienta.
